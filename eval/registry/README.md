# Параллельный тест реестра норм

Владелец эксперимента — Codex. Эта ветка содержит код парного сравнения поиска по исходным пунктам и по предварительно составленному реестру. Для запуска из репозитория нужны манифест редакций и четыре таблицы разметки в annotations/. Публикация этих таблиц ожидает отдельного подтверждения.
