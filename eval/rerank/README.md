# Отбор пяти пунктов для ответа сотруднику

Использована многоязычная модель cross-encoder/mmarco-mMiniLMv2-L12-H384-v1, лицензия Apache 2.0. Она получает вопрос и один пункт с названием документа и разделом, возвращает число для ранжирования. Для проверки достаточности источников предусмотрен отдельный эксперимент с Perplexity Decider Flash v1.3. [Карточка MiniLM](https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1) · [Карточка Decider](https://huggingface.co/perplexity-ai/pplx-decider-flash-v1.3)

## Результаты отбора

На 35 рабочих вопросах проверены 1 044 пары. Для 34 вопросов BM25 вернул по 30 кандидатов, для Q34 — 24. Метрика для прямых ответов — попадание всех эталонных пунктов в итоговую пятёрку. Порядок исходной пятёрки проверен по материалам первого прогона на 12 вопросах.

| Способ отбора | Первые 9 прямых | Следующие 19 прямых | Всего |
|---|---:|---:|---:|
| BM25 | 7 | 15 | 22/28 |
| BM25 с соседним условием | 8 | 15 | 23/28 |
| MiniLM | 7 | 18 | 25/28 |
| Первые два BM25, остальные по MiniLM | 7 | 18 | 25/28 |
| Первые два BM25, MiniLM и соседнее условие | 8 | 18 | 26/28 |

Для генерации выбрана последняя строка. Сохраняем первые два пункта BM25 и заполняем три места по оценке MiniLM. Если за первым пунктом BM25 следует условный подпункт того же уровня и раздела, уже попавший в 30 кандидатов, используем последнее место для него. Правило применяется одинаково ко всем вопросам. Системная инструкция генераторов та же, что в первом опыте.

- Появились полные основания для Q02, Q10, Q18, Q28 и Q44. ИБ 2.7 о назначении РП поднялся с 12-го места BM25 на второе у MiniLM. Пункт ДБРЦТ 1.7 о подрядчике вернуло правило соседства.
- Пропал один ранее полный ответ Q05. В пятёрке сохранился п. 1.1.1 с прямым запретом брать заявку без анкеты, но выпал родительский п. 1.1 с ролью SS. В Q22 по-прежнему отсутствует полное основание для начала работ до подписания договора.
- При четырёх вопросах на уточнение все альтернативы не собраны ни разу. Итоговый вариант вернул четыре из четырнадцати эталонных ссылок, BM25 — две. Нужность уточнения проверяем отдельно по сообщению и действию модели. У двух кейсов на эскалацию в выдаче сохранились ближайшие относящиеся пункты. Один непрофильный вопрос проверяется по ответу генератора.
- Медиана времени MiniLM на вопрос в данном запуске — 512 мс. ARM64 CPU, четыре вычислительных потока ONNX Runtime, группы по шесть пар, INT8, предел 512 токенов. Замер включает токенизацию и вычисление оценок. Загрузка весов, BM25, сеть, генератор и интерфейс в него не входят. Расход на API для этого отбора — нулевой. Время работы машины в расчёт не включено.
- Вариант выбран на рабочих данных. Финальные 15 вопросов в этот опыт не входили. Оценка релевантности модели и попадание всех ссылок в пятёрку сами по себе не подтверждают корректность ответа сотруднику.

## Запуск Gemma и Qwen

В корне репозитория, в окружении с OPENROUTER_API_KEY, выполнить одну команду:

```sh
python3 eval/rerank/answers.py
```

Сценарий использует уже рассчитанные источники, требует только стандартную библиотеку Python для Linux/macOS. Предусмотрено 70 ответов, 35 на модель. Сохраняет полные ответы с измерениями и таблицу оценок в eval/rerank/results. При повторе пропускает ранее успешно завершённые вызовы. Флаг --check проверяет вход без обращения к OpenRouter. Для первых 12 вопросов есть предыдущие ответы обеих моделей с базовой пятёркой, для остальных 23 предыдущего парного замера генераторов нет.

## Воспроизведение локального отбора

Использованные версии — Python 3.12, numpy 2.5.5, onnxruntime 1.32.0, tokenizers 0.23.3. Исходная ревизия весов зафиксирована. Для этой версии сохранён экспорт INT8 ARM64. Полные DOCX находятся в corpus. Из корня репозитория:

```sh
work=$(mktemp -d)
python3.12 -m venv "$work/venv"
"$work/venv/bin/pip" install onnxruntime==1.32.0 tokenizers==0.23.3 numpy==2.5.5
model=https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1/resolve/1427fd652930e4ba29e8149678df786c240d8825
curl -fL "$model/onnx/model_qint8_arm64.onnx" -o "$work/model_qint8_arm64.onnx"
curl -fL "$model/tokenizer.json" -o "$work/tokenizer.json"
npm ci --prefix eval/retrieval --ignore-scripts
node eval/retrieval/search.mjs --limit 30 --questions eval/rerank/questions35.jsonl --output "$work/pool.jsonl"
"$work/venv/bin/python" eval/rerank/rerank.py --pool "$work/pool.jsonl" --model-dir "$work" --out eval/rerank/rankings.jsonl
python3 eval/rerank/evaluate.py
python3 eval/rerank/freeze.py --pool "$work/pool.jsonl" --method hybrid_condition --out eval/rerank/contexts35.jsonl
python3 eval/rerank/answers.py --check
```
