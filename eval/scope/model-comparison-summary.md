# Слепое сравнение моделей на 50 вопросах

Живой прогон на коммите `cc4792e`. Для каждой из 50 пар обе реплики сверены с оригиналами регламентов. Оценки зафиксированы до открытия файла соответствия сторон моделям. Реплика считалась пригодной, если сотрудник мог использовать её без исправления действия, существенных условий, указаний или ссылок.

| Модель | Пригодные реплики | Верные действия | p50 / p95 API, с | Стоимость API, USD |
|---|---:|---:|---:|---:|
| Gemma 4 26B A4B IT | 48/50 | 49/50 | 0,6965 / 1,571 | 0,012962874 |
| Qwen3.5-122B-A10B | 49/50 | 49/50 | 3,8965 / 7,098 | 0,08891974 |

Для каждого варианта учтены 86 успешных вызовов. Задержка на вопрос включает последовательные вызовы генерации и судьи. Случаи с локальным решением входят в распределение с нулевым временем API.

Qwen исправила один существенный пропуск, добавив предусмотренный регламентом следующий шаг при выполнении указанного условия. Новых существенных ошибок при слепой сверке не выявлено. Общая ошибка обеих моделей — лишняя эскалация в случае, где оригинал даёт прямой ответ.

На этой рабочей выборке Qwen дала одну дополнительную пригодную реплику. Её медианная задержка была примерно в 5,6 раза выше, а стоимость — в 6,9 раза выше.
