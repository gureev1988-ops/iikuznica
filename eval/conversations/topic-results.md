# Влияние модели и контекста на продолжения диалога

## Восстановление вопроса для поиска

21 опубликованный ход с предысторией — десять вторых ходов процедур и одиннадцать непервых ходов диалогов. Для всех условий зафиксированы реальные предшествующие вопросы и ответы из прогона узкого варианта. Для каждой реплики использовался один и тот же промпт разбора запроса на версии `514763c`. Эталоны в модель не передавались. 84 плана перемешаны для проверки, соответствие модели и условия открыто после выставления оценок. Засчитывался пригодный для поиска вопрос после разбора ответа модели кодом. Эта метрика проверяет промежуточный шаг.

Четыре самостоятельные реплики зачтены во всех условиях. С историей только Qwen восстановила ДБРЦТ для внутренней встречи (D01.3) и расчёт себестоимости изменения проекта (P08.2). Gemma в D01.3 поняла смысл, но использовала метку связи с соседней частью вместо связи с предыдущим ходом. Обе модели выбрали УПД в D05.3, хотя требовалось уточнить, про УПД или про договор спрашивает сотрудник. Проверка подтверждает влияние представления истории и разбора ответа модели.

## Сквозное сравнение

В версии `335ff4a` следующий поиск получает самодостаточный запрос с учётом ранее разрешённой темы. Короткое заполнение известного поля обходится без модели. Во всех вариантах ответа генератор — Gemma, судья — Perplexity Decider, поиск использует BM25 и одинаковый MiniLM. В вариантах с новым состоянием менялась только модель восстановления темы. Предшествующие ответы в каждом диалоге получены соответствующим вариантом. При повторной оценке совпадающий текст с теми же источниками сохраняет прежнюю оценку, изменившийся проверяется по оригиналам. Комплект с 20 независимыми контрольными вопросами не использовался для настройки.

Для отложенной проверки заранее выбираем SHA `64afe0e` и Qwen3.5-122B-A10B на восстановление темы при условии подтверждения 50/50 на рабочем банке. Тип генератора, поиск и пороги судьи остаются зафиксированными. В промежуточном сквозном сравнении `335ff4a` этот маршрут дал 34/42, в том числе 9/10 продолжений процедур и 3/5 целых диалогов. Вариант с Gemma на восстановлении темы дал 30/42, 6/10 и 3/5 соответственно. На рабочем банке промежуточный вариант получил 49/50. В Q04 прямой ответ имел основание, но пропускал предшествующую заявку АМ в CRM.
