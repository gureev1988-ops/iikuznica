# Проверка полноты ответа о допуске к действию

Рабочая панель состоит из трёх новых вопросов на действующих учебных регламентах. Два вопроса проверяют запрет при невыполненном условии, один проверяет допустимое действие при выполненных условиях. Отдельная локальная проверка удаляет вывод о допуске из полноценного черновика и проверяет повторный поиск и адресную эскалацию.

Из корня репозитория:

```bash
python3 eval/search_core/check_permission.py
```

Для прогона с моделями нужны Node.js, Python 3.12+, переменная `OPENROUTER_API_KEY` и каталог `MINILM_DIR` с использованными в финальном сравнении `model_qint8_arm64.onnx` и `tokenizer.json`. Ранжировщик проверяет SHA-256 обоих файлов. `RANK_PYTHON` при необходимости указывает на Python окружения с NumPy, ONNX Runtime и tokenizers. Первый запуск в чистом окружении:

```bash
npm ci --prefix eval/retrieval
python3 -m venv .venv
.venv/bin/python -m pip install numpy onnxruntime tokenizers
```

Один короткий прогон:

```bash
python3 eval/search_core/check_permission.py --live \
  --model-dir "${MINILM_DIR:?укажи каталог MiniLM}" --python .venv/bin/python \
  --out "/tmp/iikuznica-permission-$(date +%Y%m%d-%H%M%S)"
```

В выходном `replies.json` лежат видимые ответы, вердикты проверки и ссылки. Нулевой код возврата подтверждает три ожидаемых решения по допуску и наличие применимых ссылок. По текстам дополнительно сверяются названные роли, обязательные условия и сохранение ответа про даты. Для закрытых наборов отдельная независимая оценка. Прогон этой панели их не использует.
