# Обратный поиск затронутых FAQ

В каталоге 16 ранее опубликованных FAQ. Для четырёх новых редакций независимый разметчик просмотрел все 64 пары и до оценки выдачи зафиксировал пять затронутых записей. На одно изменение обеим схемам разрешены три кандидата. A ранжирует по текстовому сходству (TF-IDF символьных 4-грамм); B учитывает и ранее известные ссылки на пункты, сохраняя текстовый поиск. Это проверка выбора кандидатов для последующей смысловой сверки. Попадание в тройку не даёт оснований автоматически архивировать запись.

У трёх из пяти затронутых FAQ отсутствовала прежняя ссылка на изменённый пункт. Один из них касается новой нормы. Для обновления про уборку стойки обе схемы вернули три кандидата при нуле действительно затронутых. При правке порядка вскрытия охлаждённых коробов старая связь привлекла FAQ о сухих коробах. Результат относится к этому небольшому синтетическому каталогу и фиксированному бюджету кандидатов.
