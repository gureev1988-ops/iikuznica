Всего пять запросов обошлись в $0,00416296. Изначальный валидатор требовал пояснение для каждого булева вердикта. Оба аудитора вернули полный список решений, часть положительных — без пояснений. До получения прогнозов и открытия эталонов изменили парсер: обязательны полный набор уникальных ID и булев вердикт, отрицательный вердикт исключает карточку независимо от наличия пояснения. Для расчёта использовали первую сохранённую пригодную попытку. Код и судья приняли 17/18 карточек; у T.v2.6 потерялось требование указать организацию гостя. Оригинал пункта оставался доступен. Обе попытки аудита включены в стоимость.

Поставщики вычислений для двух решающих вызовов различались. При интерпретации скорости и качества это отдельная неопределённость. Время одного пакетного запроса нельзя использовать в качестве задержки ответа чата. Пакет обогащён карточками без сокращения оригиналов, поэтому сравнение характеризует этот способ применения реестра.
