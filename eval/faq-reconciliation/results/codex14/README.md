# FAQ14 · слепой прогон в Codex

Четыре независимых экземпляра Codex получили отдельные задания. Построитель видел исходные регламенты, аудитор — регламенты и карточки. Два исполнителя решений независимо получили свои пакеты с идентичной инструкцией и одинаковыми событиями. Им не передавали эталоны или прогнозы другого варианта. Эталоны зафиксированы до получения прогнозов. Сохранены исходные ответы, вердикты по карточкам и машинный отчёт.

На F07 кадровику переслали ответ эксперта по гостевым пропускам. Оба варианта правильно распознали другую область и нашли прямой ответ для служебного пропуска, но дополнительно запросили уточнение. В инструкции действие link_rule описано главным образом для дубликата, хотя эталон предусматривает его и для прямого ответа по регламенту. Сохраняем первоначальную оценку, этот случай требует уточнения инструкции обоих вариантов перед новым закрытым тестом.

Код и аудитор приняли 18 из 18 карточек. Инструкция с исходными данными для одной пакетной проверки занимала 24 226 символов в A и 54 050 в B. Это размер переданного текста, включая повторение одних и тех же источников в нескольких случаях. Токены и деньги Codex в этом прогоне не измерялись. Данные короткие и синтетические, каждому событию заранее даны четыре кандидата, поэтому цифры не оценивают полноту первичного поиска или задержку пользовательского чата.
