## Запуск в Codex

В окружении репозитория с `OPENROUTER_API_KEY` выполни из корня:

```sh
cd eval/faq-reconciliation
out=/tmp/faq-risk24-makora
python3 risk24/live.py --cases risk24/cases.json --out "$out" --provider Makora --model google/gemma-4-26b-a4b-it
python3 score.py --cases risk24/cases.json --gold risk24/gold.json --a "$out/raw.json" --b "$out/registry.json" --out "$out/scores.json"
python3 risk24/risk.py --cases risk24/cases.json --scores "$out/scores.json" --out "$out/risks.json"
```

В каждом варианте один запрос на внешнее событие, включая сразу две кандидатные FAQ для каждой правки. Порядок вариантов чередуется. Подготовка и аудит карточек выполняются один раз. В решениях модель видит подлинный текст синтетических источников, эталон читает только локальный оценщик. Журнал сохраняет фактически ответившую модель и провайдера, расходы и технические повторы.

Считаем ошибочные снятия среди восьми действующих FAQ с самостоятельной ценностью, пропущенные из восьми противоречий, публикации, выбор источника для сотрудника, обращения к модератору и отдельные запросы на уточнение. Для демо критическими считаем любое ошибочное снятие и любой пропуск существенного конфликта. Доля конфликтов задана конструкцией теста. Нагрузку в день и экономию времени сотрудника из неё вывести нельзя.
