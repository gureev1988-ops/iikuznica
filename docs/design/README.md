# Макет и дизайн-система

[Демостенд](https://corpdoc.single-tech.ru/) открывает личный чат DION, рабочее место Отдела качества и технический раздел. Для сверки экранов скачайте один из HTML-файлов ниже и откройте его в браузере. Шрифты и стили встроены, подключение к стенду не требуется.

| Файл | Что посмотреть |
| --- | --- |
| [Интерактивный макет v29](IIznanka_Interactive_Mockups.html) | Три вкладки, расположение элементов и состояния экранов на демонстрационных данных. |
| [Дизайн-система](IIznanka_Design_System_Reference.html) | Цвета, типографика, значки и компоненты интерфейса. |

В чате стенда сотрудник может ответить на уточнение номером варианта. В Отделе качества доступны раздел «Статистика» и просмотр редакций регламентов. Права доступа и сценарии для проверки описаны в [руководстве по демостенду](../architecture/product-release.md).
